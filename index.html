✉️ Send all emails from your company Outlook

Option A: Outlook macro (classic Outlook on Windows, fastest)

  1. Click Copy Outlook macro.
  2. Open Outlook, press Alt + F11, choose Insert → Module, and paste.
  3. Click anywhere inside SendSecretSantas (the first block) and press F5. If Outlook asks to allow access, click Allow.

Alt + F11 not working? Use this instead (no editor needed): click the button, open Notepad, paste, choose File → Save as, set “Save as type” to All files, name it SendSantas.vbs, then double-click that file. Classic Outlook must be open.

You can also try Fn + Alt + F11, or File → Options → Customize Ribbon → tick Developer → Visual Basic.

Option B: Power Automate (works with Outlook on the web or Mac)

  1. Download the Excel from Stage 2. It already has Email subject and Email message columns for every person.
  2. In Excel select the data, press Ctrl + T to make it a table, and save it in OneDrive.
  3. At make.powerautomate.com create a flow: Excel Online → List rows present in a table, then Apply to each, then Outlook → Send an email (V2). Set To = Gifter email, Subject = Email subject, Body = Email message.
  4. In Body, to keep line breaks use the expression: replace(items('Apply_to_each')?['Email message'], decodeUriComponent('%0A'), '<br>')
Option C: Gmail script (only if you have a Gmail account)
  1. Click Copy auto-send script, open script.google.com, create a New project and paste.
  2. Click Run and allow permission.

Backup: send one at a time from your mail app.
